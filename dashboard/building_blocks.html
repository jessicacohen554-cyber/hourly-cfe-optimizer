Building Blocks

How each resource shapes the supply curve — and why your starting point determines your path

Every grid is a puzzle. The shape of demand — when it peaks, when it dips — determines which resources "fit" the gaps. Solar fills midday. Wind fills nights and winters. Nuclear and hydro run around the clock. Storage shifts surplus to deficit hours. But the existing clean fleet changes everything: a grid with 30% nuclear already running needs a fundamentally different build plan than one starting from scratch.

This page breaks down each resource's hourly shape, shows how they stack up against demand, and illustrates why the path from 50% to 99.99% clean looks radically different across regions. Track 1 (baseline) starts from the existing fleet. Track 2 (greenfield) builds from zero under demand growth.
