The System Value of Energy Storage

How much does each storage technology reduce total system cost? This isn't LCOE or LCOS — it's the portfolio-level value of flexibility, measured as the cost savings enabled by including each storage type in the optimization.

Storage Value by Threshold

The value of storage increases exponentially with CFE target. At 75% matching, batteries barely matter. At 99%+, they can save $5-15/MWh — because the alternative is massive renewable overbuild or expensive clean firm capacity.

Value Under Cost Uncertainty (P10/P50/P90)

Storage value varies dramatically with cost assumptions. Under Low renewable costs, storage matters less (cheap solar/wind can overbuild instead). Under High costs, storage is critical for cost containment.

Why This Matters

Storage's system value is fundamentally different from its standalone cost. A battery with $200/kWh LCOS that saves $8/MWh at the system level is economically justified even if its standalone economics look marginal. Portfolio value > component cost.

For storage developers: This quantifies your technology's value proposition beyond LCOS. When pitching to utilities or corporate buyers, the relevant metric is system cost reduction — and these numbers show it ranges from near-zero at low thresholds to transformative at 95%+.

For grid planners: The exponential increase in storage value past 90% CFE reveals why long-duration storage (LDES, Green H₂) becomes essential for the last mile. Short-duration batteries hit diminishing returns earlier.

For investors: The P10/P50/P90 fan shows storage's value robustness. If a technology delivers savings under 90% of cost scenarios, that's a strong investment signal regardless of any single LCOE forecast.
