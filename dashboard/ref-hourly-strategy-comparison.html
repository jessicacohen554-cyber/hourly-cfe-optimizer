Which Hourly Matching Strategy Actually Builds the Grid We Need?
Three approaches to 24/7 clean energy procurement — from pure additionality to pragmatic policy alignment. Same hourly matching constraint, radically different resource deployment, cost, and grid outcomes.

The Three Strategies

All three strategies require hourly matching — every hour of demand must be covered by a contracted clean resource generating in that hour. They differ in what counts as "your" clean energy and how existing grid resources are treated.

Strategy 2A

All New-Build

100% additionality. Every MWh must come from a newly built resource contracted via PPA. No credit for existing clean energy on the grid.

SSS: Ignored • Baseline: Fossil fuel • CO₂: All new displaces fossil
Strategy 2B

Grid Baseline

Pro-rata share of the existing grid mix is free. Only procurement above the grid's existing clean share requires new-build PPAs.

SSS: Implicit in grid mix • Baseline: Grid clean % • CO₂: Only above-baseline displaces
Strategy 2C

SSS + Tranches

State-sponsored clean (nuclear ZEC/CMC, state hydro) allocated free as Layer 1. Remaining need filled via merit-order tranches: merchant existing, uprates, then new-build.

SSS: Explicit free layer • Baseline: SSS + existing • CO₂: Only new-build displaces

The Additionality Paradox

Pure additionality (2A) maximizes new investment per buyer dollar but at steep cost. Lower-additionality strategies (2C) achieve comparable grid decarbonization cheaper — but only because they credit existing clean that was already running. The question: is "not free-riding" worth the premium?

The Nuclear Question

Nuclear provides the 24/7 firm power that high-threshold hourly matching demands. Strategy 2C explicitly supports it via SSS. But state programs expire: NJ ZEC (2026), IL CMC (2028), NY ZEC (~2030). When they do, nuclear shifts to the merchant pool under federal 45U PTC ($15/MWh). How does this change outcomes?

Participation Equivalence

Different strategies need different participation rates to achieve the same grid decarbonization. 2A's higher cost per buyer may limit adoption, while 2C's lower cost could attract more participants — potentially offsetting the lower per-buyer additionality.

Regional Deep Dives

Strategy outcomes vary dramatically by region. SSS-heavy ISOs (PJM, NYISO) see the biggest spread between strategies; ERCOT with zero SSS shows near-convergence.
