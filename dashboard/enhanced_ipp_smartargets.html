1Framework Overview

The Enhanced IPP SMARTargets framework extends the base SMARTargets V1 market simulation with a full parametric sweep across 5 independent dimension axes. Instead of 8 hand-crafted scenarios (R1/R2, AT1–AT4, QT1–QT4), the sweep generates 270 scenarios per sweep type from the Cartesian product of shared data sources already used throughout the pipeline.

The core insight: rather than picking “Facilitating” vs “Challenging” as binary bundles, decompose the uncertainty space into its independent axes and sweep all combinations. The P10/P50/P90 fan bands that emerge capture the true uncertainty envelope — including scenarios that are facilitating on one axis but challenging on another.

Three sweep types are available, each producing 270 scenarios:

  • Reference — No emission constraint. Pure profit-driven deployment.
  • Power Net-Zero — Power sector net-zero by 2050 (AT trajectory).
  • Economy Net-Zero — Economy-wide net-zero (tighter AT trajectory).

Total: 810 scenarios across all sweep types, each simulated across 7 ISOs × 6 time steps (2023–2050).

The asymmetric keys (high_vre_low_firm and high_firm_low_vre) capture structural cost divergence: a world where VRE costs stall while firm generation gets cheap (favorable for nuclear/CCS), or vice versa. The price sensitivity maps to the existing step10 cost model via:

  • firm key → lcoe_level (drives nuclear, CCS, geothermal LCOE)
  • fuel key → fuel_level (drives wholesale LMP via fossil merit-order)
  • tx key → tx_level (transmission adder on VRE and clean firm)

Effective LCOE = base LCOE × (1 − effective discount)
A “High PPA” scenario in SPP provides only 11% VRE cost reduction vs 22% in ERCOT. This regional asymmetry means PPA policy has twice the impact in liquid markets — which is where most corporate procurement already concentrates.

7Axis 5: Gas Friction

Controls how freely new gas-fired generation can be built when demand exceeds clean supply. Represents the aggregate effect of ESG pressure, permitting delays, policy moratoriums, and siting opposition.

LevelFriction FactorInterpretation
Low0.3Near-moratorium. Strong ESG + policy barriers. Only 30% of economically justified gas gets built.
Medium0.7Moderate friction. ESG/siting delays reduce pipeline by 30%.
High1.0No friction. Gas builds freely wherever profitable.
gas_built_gw = (unserved_twh / (8.760 × 0.85)) × gas_friction
where 0.85 = assumed CCGT capacity factor

Gas friction interacts strongly with demand growth: high demand + low gas friction creates the widest gap between load and supply, forcing either mandated clean build (under emission constraints) or load curtailment.

8Ratcheting Floor Mechanism

Deployment is irreversible. The simulation enforces a strict ratcheting floor on clean energy share:

  • Clean percentage only increases — state[‘clean_pct’] is set to each deployed zone’s threshold and never decremented.
  • Candidate thresholds filter upward — each year only considers zones above the current clean% floor.
  • Cumulative GW ratchets — the Wright’s Law tracker only adds capacity, never subtracts. Earlier deployment permanently reduces future costs.
  • Physics floor from Step 3 — resource mixes at each threshold come from pre-computed PFS results that encode the minimum physical requirement to serve that clean% of demand.
This creates path dependency: a scenario that reaches 70% clean by 2035 has a fundamentally different cost trajectory than one that reaches 70% by 2045, because the earlier deployer benefits from more Wright’s Law learning and a higher cumulative GW baseline.

The sequential stepping loop processes zones in order for each year:

  1. Start from previous year’s ending clean% (the floor)
  2. Evaluate profitability of the next zone (revenue − cost)
  3. If profitable: deploy, advance floor, update cumulative GW, reduce queue budget
  4. If unprofitable: market stop — no further deployment this year
  5. Under emission constraints: mandated deployment fills gap between market stop and cap

9Cost Model & PPA Integration

The cost model computes blended LCOE ($/MWh) for incremental resources in each zone, with three layers:

  1. Base LCOE — from pipeline_config LCOE tables, indexed by lcoe_level and ISO. Includes Wright’s Law learning applied via deployment-based cumulative GW.
  2. Transmission adder — from TX_TABLES indexed by tx_level and ISO. Applied to VRE, clean firm, and offshore wind.
  3. PPA discount — reduces effective LCOE by the region-scaled PPA premium. Applied to all clean energy resources.
effective_lcoe[res] = (base_lcoe[res] + tx_adder[res]) × (1 − ppa_discount[res, iso])

The blended zone cost is the TWh-weighted average across all incremental resources in the zone.

10Revenue Model

Revenue combines three streams, computed from 8,760-hour dispatch profiles:

StreamMethodKey Parameters
Energy (LMP) Hourly generation × hourly LMP, then generation-weighted average Fossil merit-order stack from Step 5B; fuel_level sensitivity
Capacity ELCC × degraded capacity price ÷ (CF × 8,760) Capacity price degrades with clean share (alpha = 0.35–0.40); ERCOT/MISO/SPP = $0
REC Scarcity-driven compliance: ACP × (1 − exp(−k × gap%)) Per-ISO calibrated against 2025 observed REC prices; CES ISOs give nuclear/CCS 60% of Tier 1

Blended revenue is the resource-share-weighted sum of all three streams. The profit test is:

profit = blended_revenue − blended_cost
If profit > 0: deploy zone. If profit ≤ 0: market stop.

12Output Structure & Statistics

The sweep produces a single parquet file per sweep type with one row per scenario × ISO × year (270 × 7 × 6 = 11,340 rows for reference). Each row contains:

  • Dimension keys: scenario ID, conditions code (F/C), demand_growth, price_sens, ppa_level, gas_friction
  • Market outcomes: clean_pct, avg_lmp, lmp_p90, cost_per_mwh, revenue_per_mwh
  • Emissions: emissions_mt, gross_emissions_mt, emission_rate, emission_cap_mt
  • Deployment: gas_built_gw, total_gas_gw, queue_used_gw, market_stop flag
  • Policy cost: mandated_subsidy_mwh, cumulative_subsidy_mwh, dac_offset_mt, carbon_shadow_price
  • Resource mix: mix_{resource}_twh for each of 8 resource types

A companion JSON summary provides per-ISO P10/P50/P90 statistics at 2050 for key metrics (clean_pct, emissions_mt, avg_lmp).
