The Two Strategies

Strategy 1A

1A — Consequential

Cross-regional new-build deployment via queue-ordered procurement using a fossil-average emission baseline. Deploys mostly mature VRE (solar, onshore wind) across any ISO. Cheapest per-MWh, but annual accounting misses hourly mismatches between clean generation and actual load. Provides zero financial support to existing nuclear plants.

Strategy 2C

2C — Hourly Matching with SSS

Same-ISO hourly matching blending existing clean resources (Surplus Supply Stack, merchant EAC, nuclear uprate) with new-build. Clean generation must match load every hour in the buyer's grid — forcing deployment of firm clean and storage. Creates EAC revenue that keeps existing nuclear economically viable.

Proposed GHG Protocol Scope 2 Revision: Strategy 2C represents the hourly matching framework under active consideration for the GHG Protocol Scope 2 standard revision. Unlike annual matching (which allows temporal arbitrage), hourly matching requires clean energy to be generated in the same hour it's consumed — ensuring corporate procurement drives real-time grid decarbonization rather than paper accounting.

Strategy Crossover

Per-MWh Cost Favors 1A

Consequential netting procures cheap cross-regional VRE — solar and onshore wind at wholesale prices. On a per-MWh basis, 1A is consistently cheaper. But this metric hides the full system cost.

System Cost Tells a Different Story

1A's VRE-heavy mix requires massive gas backup for reliability. When you include new-build gas capacity costs, the total system cost flips. Above a critical participation threshold, 2C becomes the cheaper system-wide strategy.

CO₂ Displacement

Both strategies reduce emissions, but through fundamentally different mechanisms. 1A displaces fossil generation cross-regionally via additionality. 2C restructures the buyer's own grid — blending existing clean with new-build to match load hourly.

Gas Lock-in: The Hidden Cost

This is where the strategies diverge most dramatically. 1A leaves substantially more gas on the grid — creating political constituencies and infrastructure that resist retirement. 2C's hourly constraint forces firm clean + storage deployment, directly displacing gas.
