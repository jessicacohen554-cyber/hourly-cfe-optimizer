## Prompt 0: Reconcile dvre.html and Output Deck

> **Goal:** Make `dashboard/dvre.html` and `data-center-cfe/output/vre-investment-thesis-deck.html` consistent — same slides, same data, same narrative, same ordering.

### Context

Two versions of the VRE deck exist:
- **Output deck** (`data-center-cfe/output/vre-investment-thesis-deck.html`): Generated by `generate_deck.py` + `templates/deck_template.html`. Currently **16 slides** (after Slide 6 Energy Timeline and Slide 7 Colocation Developers were added).
- **Dashboard deck** (`dashboard/dvre.html`): Standalone HTML presentation. Currently **13 slides** — missing the two new slides and potentially other differences.

### Prompt

```
Read both files:
1. data-center-cfe/output/vre-investment-thesis-deck.html (16 slides)
2. dashboard/dvre.html (13 slides)

Do a slide-by-slide comparison:
- Identify slides present in one but not the other
- Flag any data/number differences between matching slides (e.g., different TWh figures, different GW totals, different ISO ratings)
- Flag narrative/framing differences
- Flag visual/chart differences

Then make dvre.html match the output deck exactly:
- Add any missing slides (Slide 6 Energy Timeline, Slide 7 Colocation Developers, and any others)
- Update any stale numbers or narrative
- Preserve the dvre.html styling system (it may use dashboard shared.css vs the output deck's inline CEG styles) — match content, not necessarily CSS
- Renumber slides to match

After syncing, verify both decks have identical slide count, ordering, and data.
```

### Files to Read
- `data-center-cfe/output/vre-investment-thesis-deck.html`
- `dashboard/dvre.html`
- `data-center-cfe/templates/deck_template.html` (for understanding generation pipeline)

### Success Criteria
- Both decks have the same number of slides
- All data points match (TWh, GW, $/MWh, ISO ratings)
- New slides (Energy Timeline, Colocation) present in both
- No orphaned or stale content in either version
